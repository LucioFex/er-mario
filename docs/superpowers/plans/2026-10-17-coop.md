# ER Mario co-op (Seamless + Luigi) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two players in Seamless Co-op (on Elden Ring Reforged) see each other as Mario and Luigi, and the guest's blows count on the host.

**Architecture:** A Steam P2P side channel (`SteamNetworkingMessages` from the game's own `steam_api64.dll`, channel `CHANNEL`) carries the Mario pose (31 parts, ~30 Hz, unreliable), the guest's hits (reliable) and friendly shoves. The peer comes from `CSSessionManager`; its `PlayerIns` is matched by `player_network_session.remote_identity`. Without a session nothing runs: single player is unchanged.

**Tech Stack:** Rust (cdylib), fromsoftware-rs `eldenring` crate, glam, steam_api64 flat API via GetProcAddress.

## Global Constraints
- Single player must behave exactly as before (every co-op path is gated on an active session).
- Mario always wears chest row 660100, Luigi 661100 (Vagabond Knight Armor (Altered)); on each PC the local character's row shows model 999 (998/997 caps), the other row model 996 (the other character's colours).
- Guest: no grabs (carry, swing), no enemy movement (knock, juggle, trample push, fireball push, hook drag); hp written locally as a prediction but never below 1 and never finished locally: the host applies and kills.
- Friendly fire: blows only push the partner (SM64 soft knockback, no damage).
- Never commit the ROM or built package files.

## Files
- Create `src/net.rs`: steam_api64 SteamNetworkingMessages wrapper (send, receive).
- Create `src/coop.rs`: session, packet codec (unit tested), pose send/receive/interpolation, remote apply, guest hit forwarding, shoves.
- Modify `src/engine_mario.rs`: `apply_remote(chr, pose)`, root-follow only for the local player.
- Modify `src/lib.rs`: call `coop::frame`, `coop::apply_remote` in the pose tasks, host hit intake, shove intake.
- Modify `src/combat.rs`: `Attack::code/from_code`, guest forwarding in `deal`, `Combat::remote_hits`, row checks.
- Modify `src/knock.rs`, `juggle.rs`, `carry.rs`, `swing.rs`, `trample.rs`, `fireball.rs`: guest guards.
- Modify `src/equip.rs`: per-character chest row and partner model.
- Modify `src/assets/mod.rs`, `src/assets/tex.rs`, `src/assets/archive.rs`: partner model 996, `base_assets`.
- Modify `src/paths.rs`: `package_dir` (ini key, Reforged `dll\offline` layout -> `addons\er-mario`).
