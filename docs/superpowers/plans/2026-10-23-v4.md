# ER Mario v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** v4 of the spec `docs/superpowers/specs/2026-10-23-v4-design.md`, part by part (0 → 8). This
file holds Parts 0 and 1; each later part gets its own section here when it starts.

**Architecture:** Rust mod (`src/`) driving libsm64 (C, `libsm64/src/decomp/game/`) on a worker thread
(`worker.rs`), one `worker::call` per SM64 tick from `lib.rs` `frame()`; requests (`moves::Request`)
are applied in the worker right before `sm64_mario_tick`; hits are measured in the worker by
`combat::hits`. Part 1 adds data-driven moves: Rust evaluates a move's keyframes into a per-tick frame
that C's `ACT_ER_SCRIPT` / `ACT_ER_SCRIPT_AIR` apply.

**Tech Stack:** Rust (glam, fromsoftware-rs `eldenring` 09a4208a), C (SM64 decomp in libsm64,
clang-cl), Windows, Elden Ring 2.7.2 vanilla.

## Global Constraints

- Tests: `cargo test --release --lib` with build.ps1's env (scratchpad `test.ps1`); build + install:
  `cmd /c powershell -ExecutionPolicy Bypass -File build.ps1 -Dist C:\ER-Mario` (vanilla only:
  Reforged has no 2.7.2 build yet).
- Pillar: every move/system is judged by "more DYNAMIC": Mario rarely still > ~1 s, ground → air →
  ground strings with a closer and a swap, any landed blow dash-cancellable (hammer heavies excepted).
- Sounds only SM64 ROM (or mod-synthesised), soft when repeated (`sm64_play_sound_volume` ~0.1-0.3).
- Weapons/objects real 3D; fluid animation (anticipation, follow-through, blends, squash & stretch).
- Not OP: string fades, cooldowns, bosses a few % per blow. Root-cause fixes only.
- Co-op stays compatible: new `Attack` variants are appended at the END of combat.rs `CODES`; packet
  changes forward-compatible (sized records / unknown kinds skipped) or `VERSION` bumped. Tell the
  user when the co-op DLL changes (release coop-2026-10-17 + the other PC).
- Never drive the game or fight in the user's save without asking.
- Code, commits, README in English; talk to the user in Spanish.
- Every part ends with: review subagent on the diff, fixes, build + install, commit + push (README:
  controls, moves, damage table), memory update, short "what to test / log lines" list.

### Task 1.1: C script actions

**Files:** create `er_script.c`; modify `sm64.h`, `libsm64.h`, `mario_actions_object.c`,

**Interfaces (produces):**
```c
#define ACT_ER_SCRIPT     0x0080039C // (0x19C | ACT_FLAG_STATIONARY | ACT_FLAG_ATTACKING)
#define ACT_ER_SCRIPT_AIR 0x0080089E // (0x09E | ACT_FLAG_AIR | ACT_FLAG_ATTACKING)
struct SM64ErScript {
    int32_t active;        /* set for this tick (cleared once used) */
    int32_t end;           /* the move is over: idle / walking / freefall */
    int32_t animId;        /* SM64 animation, -1 keep */
    float animFrame;       /* its frame (remapped time); < 0: let it play */
    float twist, pitch, roll; /* drawn body, degrees from his facing */
    float turn;            /* degrees his facing turns this tick (+ left) */
    int32_t aim;           /* 1: turn to the aimed enemy now (er_aim_turn) */
    float forwardVel;      /* units per tick along his facing */
    int32_t setVelY; float velY; /* vertical speed this tick */
    int32_t hold;          /* air: no gravity (vertical speed 0 unless setVelY) */
    int32_t landEnds;      /* air: landing ends the move (else it goes on on the ground) */
    float squash, dip;     /* er_squash */
    int32_t invulnerable;  /* invincTimer kept up */
    int32_t locked;        /* er_move_locked */
    uint32_t sound; float soundVolume; /* this tick's sound (0 none; volume <= 0: at his body) */
};
SM64_LIB_FN void sm64_er_script(int32_t marioId, const struct SM64ErScript *frame);
SM64_LIB_FN int32_t sm64_er_script_size(void);
```
Behaviour: the frame is copied into a static; `act_er_script` (ground): end → `ACT_IDLE` (or
`ACT_WALKING` with stick); animation + frame; turn/aim; forward vel; `setVelY && velY > 0` → air
action keeping `actionTimer`; `perform_ground_step` left ground → air action keeping the timer;
body angles, squash, invuln, locked, sound; `actionTimer++`; clears `active`. Not active → ends.
`act_er_script_air`: same, `perform_air_step`; hold → vel[1] = 0 before and after; landed →
`landEnds` ? `ACT_FREEFALL_LAND`-style stop (idle) : ground action keeping the timer; wall →
forward 0. Timer kept across ground↔air (save/restore around `set_mario_action`).

- [ ] Step 1: Rust test in `sm64.rs`: `unsafe { sm64_er_script_size() } as usize == size_of::<SM64ErScript>()`.
